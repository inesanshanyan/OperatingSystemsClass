# Homework 8 — File I/O

Seven small programs that use `open`, `read`, `write`, `lseek`, and `ftruncate`. Each task is its own file.

## Build

From this directory:

```bash
gcc -Wall -Wextra -std=c11 -o assignment1 assignment1.c
gcc -Wall -Wextra -std=c11 -o assignment2 assignment2.c
gcc -Wall -Wextra -std=c11 -o assignment3 assignment3.c
gcc -Wall -Wextra -std=c11 -o assignment4 assignment4.c
gcc -Wall -Wextra -std=c11 -o assignment5 assignment5.c
gcc -Wall -Wextra -std=c11 -o assignment6 assignment6.c
gcc -Wall -Wextra -std=c11 -o assignment7 assignment7.c
```

Assignments 2, 4, 5, and 6 create `data.txt`, `log.txt`, `sparse.bin`, and `numbers.txt` in the current directory.
